### info

this is a 2d platformer made in godot with 3 levels. the assets used are NOT mine, they're linked at the bottom. the first level was made using this [youtube tutorial](https://youtu.be/LOhfqjmasi0?si=EwdhvdudPdSf-5rC), however it does have changes such as a double jump powerup and a very cool way to switch levels, which is jumping onto a mushroom. the next two levels also have a buncha powerups, a few ways to kill slimes, and a very nice interactive thingy with a dragon and fruits and a wizard :3.
